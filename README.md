# 🚀 C++-oop-problems

## 📖 About

This repository contains a collection of **C++ solved problems** implemented using Object-Oriented Programming (OOP) concepts. Each program focuses on applying C++ to solve practical problems rather than explaining theory.

---

## 🧠 What You'll Find

* Solved C++ problems using OOP approach
* Practical implementations of real coding questions
* Clean and readable code for learning and revision
* Variety of problem-solving examples

---

## ⚙️ How to Run

1. Compile the program:

```bash
g++ filename.cpp -o output
```

2. Run the program:

```bash
./output
```

* Practice problem-solving using C++

* Improve coding logic and implementation skills
