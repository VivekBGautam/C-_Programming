# Assignment 5

This folder contains all the warmup programs written in C++. Each program performs the following tasks:

program5_1.cpp – Check whether a number is even or odd

program5_2.cpp – Find the maximum number out of two numbers

program5_3.cpp – Check whether the input year is a leap year or not

program5_4.cpp – Check whether a number is positive or negative

program5_5.cpp – Find the maximum number out of three numbers

How to Execute the Programs

Use the following commands in the terminal to compile and execute the .cpp files:

Compile
g++ filename.cpp -o myexe

Run
myexe
